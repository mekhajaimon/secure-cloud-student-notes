# Cloud-Based Student Notes Management System

A secure cloud-based web application developed using Flask and deployed on AWS EC2. The system allows users to register, login, add notes, view notes, edit notes, delete notes, and logout.

## Features

- User Registration
- Secure Login
- Password Hashing
- Add Notes
- View Notes
- Edit Notes
- Delete Notes
- Admin Dashboard
- Rate Limiting
- Security Headers
- HTTPS/SSL using Nginx
- AWS CloudWatch Monitoring
- Automated Backup Script
- GitHub Actions CI Pipeline

## Technologies Used

- Python
- Flask
- MySQL
- HTML, CSS, Bootstrap
- AWS EC2
- AWS S3
- AWS CloudWatch
- Docker
- GitHub Actions
- Nginx
